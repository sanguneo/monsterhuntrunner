# Concept-first hunter revision

The 2026-10-31 generated concept `hunter-concept.png` is a visual reference, not a finished 3D render or a promise of runtime fur rendering. The user rejected the preceding hunter as stiff and LEGO-like; that checkpoint is superseded.

Use the large three-quarter hero as the canonical anatomy: one upright ear and one bent floppy ear, consistently across front/back views (the generated turnaround is inconsistent). Preserve the shipped rabbit identity and gameplay pose/socket contracts.

Translate relaxed weight, dropped shoulders, bent knees, slender forearms, expressive eyes, continuous soft body volumes, an open flowing teal coat and cream shirt into efficient game geometry. Do not merely round segmented blocks, or reproduce expensive individual fur strands. The other bosses borrow organic construction and gesture, never the rabbit identity.

`species-concept.png` guides anatomical identity of wolf, zombie dog, crow and shark.
Use their flowing anatomical silhouette and differentiation, not dense hair/feather
strands. Generated reference is not proof that the exported meshes match it.
